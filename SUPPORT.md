# Support

## Using the application

Visit [PDF Tools](https://akshat4112.github.io/pdf-tools/), [help and FAQ](https://akshat4112.github.io/pdf-tools/help/), [guides](https://akshat4112.github.io/pdf-tools/guides/) and [limitations](https://akshat4112.github.io/pdf-tools/limitations/) before reporting an issue.

If a file fails, check the displayed format and size limits, try a small synthetic example, and record the tool, browser version, steps and expected result. Review outputs before sharing; retain the original documents.

## Reporting problems

Use [GitHub issue templates](https://github.com/Akshat4112/pdf-tools/issues/new/choose) for ordinary bugs and suggestions. Public issues are not a confidential support channel. Never attach private documents, personal data or credentials. Follow [SECURITY.md](SECURITY.md) for security-sensitive reports.

Community support is provided without a guaranteed response time.
