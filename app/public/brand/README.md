# PDF Tools brand assets

Usage, provenance, dimensions, licenses and integration handoff: [PT-BRAND-003](../../../docs/brand/PT-BRAND-003-asset-kit.md).

Open `index.html` for the responsive asset review sheet. SVG sources are editable; PNG/ICO files are ready exports. Rebuild with `python scripts/build_brand_assets.py` from the repository root (fontTools, Inkscape, ImageMagick convert required only for regeneration).

Original geometry/artwork: [MIT](../../../LICENSE). Outlined typography derives from the existing OFL font; see [FONT-LICENSE.txt](FONT-LICENSE.txt). Keep the notice with redistributed source kits. No runtime fonts or remote resources are needed.
