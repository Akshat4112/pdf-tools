# Roadmap

This is a direction-of-travel document, not a delivery promise. See the [canonical tracker](https://docs.google.com/spreadsheets/d/1m3iyaksGD-hY51JwFfIzb-JS5S3GSp0uJqS4Ae77-lg/edit) for authoritative scope and dependencies.

| Area | Direction |
| --- | --- |
| Foundation and core tools | Reliability, usability, accessibility and verified PDF outputs |
| Editing and forms | Editor workflows, forms and visual signatures subject to acceptance |
| Advanced local processing | Evaluate OCR, compression, protection, redaction and related workflows |
| Conversions | Release only supported, validated format subsets |
| Optional backend | Requires explicit decisions on budget, hosting, consent and privacy |

Planned capabilities are not shipped features. See [available tools](README.md#available-tools) for the current product. This document does not add tasks to the existing backlog or commit to dates.
